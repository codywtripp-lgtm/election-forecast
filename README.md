# election-forecast

An independent, open-methodology forecast of US elections, starting with the November 3, 2026 midterms (Senate, governor, House).

Status: **design stage.** See:
- [Methodology](docs/METHODOLOGY.md)
- [Architecture](docs/ARCHITECTURE.md)
- [Data sources & gaps](docs/DATA_GAPS.md)
